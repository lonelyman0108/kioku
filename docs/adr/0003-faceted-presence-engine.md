# 0003. 受控多维切面词表、蕴含展开与提问破壁存在感引擎

- 状态：生效（2026-11-18）
- 日期：2026-11-18

## 背景

在多物理设备、多代码仓库与多生活圈并行工作的场景下，全量塞入所有高优先级记忆会挤爆客户端的启动上下文预算并造成规则混淆（如将个人项目习惯带入公司仓库，或在 Windows 终端执行 macOS 命令）；但如果简单把异地记忆死过滤掉，用户在公司电脑显式询问家里网络拓扑或跨机器配置时又无法找回知识。同时，自由无约束的扁平标签容易因模型拼写不一致而分裂，也无法区分「同一维度相斥（`win` vs `mac`）」与「跨维度通用（未标环境）」。

## 决策

1. **受控多维切面词表与蕴含展开**：内置四大维度——`realm`（场域：如公司/家里/个人）、`env`（环境与设备：如 `win`/`mac`/`linux`/`wsl`/具体机器）、`runtime`（客户端家族）与 `project`（随会话上报自动登记的项目仓库名），并支持自定义维度（如 `role` 角色帽）。每个维度标明同维模式（`exclusive` 互斥聚焦 / `additive` 非互斥叠加）；词表项支持 `implies` 蕴含展开（最多 4 层且禁止成环，如设备 `office-pc` 自动展开 `env:win` + `realm:公司`，项目蕴含场域优先于终端默认场域）与 `aliases` 口语触发词；记忆圈支持设置 `default_facets` 免除圈内词条重复打标。
2. **启动编译相斥隐身**：会话启动（`boot`）合成当前在场切面后，剔除任一 `exclusive` 维度与当前焦点发生冲突的变体切片，将无冲突的通用底座与同频切片按特异度排序拼合，并允许关联个人圈中无任何互斥切面限制的纯通用 `P0` 词条穿透注入。
3. **召回基础门槛、亲和加减权与点名破壁**：每轮召回先基于语义相似度、全文 BM25 与关键词计算基础相关性分 $S_{\text{base}}$，仅当达到门槛（默认 `0.12`）才进入切面亲和调制，防止无关记忆靠标签分凑分冒头；同维命中加分（上限 `0.28`），互斥维度冲突扣分（上限 `0.32`），关联客场圈及跨群印象附加轻微折减。若用户提问命中词表口语触发词（如「家里」「Mac」），当轮临时切换或追加对应维度焦点，使原本退居幕后的异场域/客场圈知识准确浮现（受硬边界安全矩阵约束）。

## 后果

- 实现了「主场高存在感、冲突零干扰、点名能破壁、秘密硬隔离」的动态激活体验。
- 模型写入时不强制继承访问密钥全部标签，由受控词表清单引导按语义打标，配合后台整理（`Dream`）巡检补标、多变体归拢与跨项目共性去标上浮。
- 召回调试台与事件记录需要展示 `facet` 与 `link` 得分拆解以及触发词翻转后的有效焦点，便于人工排查调优。

## 可推翻条件

相关性门槛、各维加减权系数及客场折减参数均作为可调高级设置项管理；若后续需要支持更复杂的复合布尔表达式切片条件，可在不改变词表模型的前提下扩展 `when` 求值器。
