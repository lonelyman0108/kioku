# 0002. 以自动短 ID、多切面变体与双链取代多级 URL 路径树

- 状态：生效（2026-11-18）
- 日期：2026-11-18

## 背景

从 Lore 继承的多级路径坐标（`<domain>://<位置>/<标识>`）在多端、多场景记忆体系下带来了四个结构性问题：
1. **单亲树无法表达多维交叉**：同时涉及「公司」「Windows」「家里网络」的记忆难以选择唯一父路径；
2. **身份地址与分类耦合**：修改归属或位置就必须 `move` 改变坐标，导致外部引用与内部关联断链，并迫使服务端维护复杂的 `claimUri` 过期释放与 409 占坑检测逻辑；
3. **跨环境规范打架**：Git 规范、终端环境等同一主题在不同机器与场域下的要求相反，拆成多条独立卡片后容易在启动加载或召回中互相污染；
4. **记忆物种割裂**：对话抽取的联系人事实（`fact`）与会话摘要（`episode`）没有坐标、不建向量索引，导致超过直连条数上限后的远期事实彻底遗忘。

## 决策

1. **废除多级 URL 路径树，采用自动短 ID + 标题寻址**：所有词条由服务端自动生成不可变的无歧义 Base30 短 ID `m-<6位>`（字符集 `23456789abcdefghjkmnpqrstvwxyz`，输入大小写不敏感、存储统一小写，碰撞重试），配合自然语言标题与非互斥主题标签 `topics` 进行组织与动态聚合浏览。彻底移除 `move`、`claimUri` 与路径占用冲突，保留 `legacy_uris` 表仅作旧数据迁入后的读取重定向兜底。
2. **统一词条物种与持久检索**：正式词条（`entry`）、联系人/群事实（`fact`）与会话摘要（`episode`）共用 `entries` 表与短 ID 体系；非机密且有效的 `entry` 与 `fact` 均建立 1024 维向量索引与全文索引，支持远期事实按作用域语义召回与一键提炼升级。
3. **引入「词条头 + 多切面变体（`entry_variants`）」**：普通记忆退化为单个无条件切片（`when = {}`）；跨环境同主题记忆可在同一词条下挂多个带 `when` 条件的切片。启动加载时剥离互斥切片并将底座与匹配切片编译合并；向量与全文索引建立在切片粒度上，召回聚合至词条；机密级（`secret`）词条下所有切片正文统一信封加密（`aad` 绑定 `variant:<id>`）。
4. **支持 `[[m-xxxxxx]]` 双链图谱与 1 跳语境扩散**：写入时线性扫描正文中的双链标记维护 `entry_links`（`secret` 词条与 `untrusted` 未确认来源不写明文出链）；输出时仅为调用方当前可读的目标补全最新标题；召回对高分种子词条检查 1 跳双向可读邻居，将与当前在场切面同频共振的邻居衰减并入候选（标记 `via: link`）。

## 后果

- 彻底消除命名负担与搬家断链，同主题多环境规范可在一处集中维护与对比。
- 读取、修改、加密与历史快照需围绕「词条头 + 变体切片列表」重构契约与 MCP 工具签名（如 `kioku_get`、`kioku_browse` 取代旧的 `kioku_list` 与 `kioku_move`）。
- 迁入工具需要将旧版 Kioku 与 Lore 的路径拆分为 `topics` 与 `legacy_uris` 映射。

## 可推翻条件

若单圈词条量级突破千万级导致 6 位 Base30 短 ID 接近碰撞阈值，可将新生成短 ID 扩展至 8 位并保持校验正则向下兼容旧 6 位 ID。
