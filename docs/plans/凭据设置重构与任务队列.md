# 凭据设置重构与后台任务队列计划

在保留 Kioku「纸墨线框（Paper & Ink）+ 零圆角 + 零阴影 + 1px 墨线 + 砖红唯一强调色 + 纯系统字体」视觉底子的前提下，系统升级后台任务队列与异常恢复体验、复合托管凭据底座与多入口捕获闭环，并将凭据页与设置页收口至与记忆/整理一致的工作台语法。

## 1. 目标与核心设计决策

- **后台顺序任务队列与抽屉异常置顶（0 DDL，保持 12 表架构）**：
  - 复用 `pg-boss` `dream` 队列（`policy: 'singleton'`，同一 `singletonKey` 天然支持多条 `created` FIFO 排队且同时仅 1 条 `active`），移除人为内存锁，实现串行顺序队列；
  - 按规范化任务签名 `(mode, scope, limit, all, pinnedFirst, sorted(targetShortIds))` 对运行中与等待队列去重，等待队列上限 **5 项**（不含运行中 1 项），重复或超限时明确拒绝；
  - 将每小时 41 分定时探测解耦至独立轻量队列（`dream-cron`），当存在运行中或等待中的整理任务时自动顺延至下一周期，不插队、不污染手动队列；
  - 前序任务遇错采用分级策略：手动取消、普通失败或部分失败（`partial`）后自动续跑队列下一项；检测到上游致命故障（`auth` 鉴权失效、`not_found` 模型不存在、`quota` 额度熔断）时自动中止并取消剩余等待队列项，防止雪崩；
  - 向量索引补齐维持独立并行通道，与记忆整理互不阻塞，同时修复缺失向量数为 0 时空发任务的问题；
  - 后台任务抽屉彻底降噪并按紧急度排布 4 块：**异常任务置顶**（展示未重试且未忽略的 `failed`/`partial`，支持点击失败短 ID 直达记忆编辑页、描边按钮一键重试全量或失败子集、幽灵按钮忽略）→ **记忆整理**（1px 竖线串联当前项与 `#1/#2…` 等待项，支持单项移出与清空队列）→ **向量索引**（空闲单行折叠、补齐时展开进度卡）→ **近期记录**（默认折叠，已取消项支持低强调重新发起）；修复连续队列吞 Toast 缺陷并解锁整理页排队发起。
- **复合托管凭据安全与字段模型（库内全量密文 + 明文属性受控直出）**：
  - 所有凭据字段值（包括 `url`、`host`、`username` 等非机密属性）在数据库中仍统一经 AES-256-GCM 密文存储，仅非敏感元数据（`kind`、`primary_field`、`field_meta`、`passkey_manual_only`）明文落库供列表筛选、占位符校验与 MCP 字段目录透出；
  - 统一 5 套模板全员具名字段 + 默认字段：`secret`（`value`）、`login`（`url`/`username`/`password`/`recovery_codes`，支持 Passkey 人工登录标记）、`api`（`endpoint`/`token`/`api_secret`）、`database`（`host`/`port`/`database`/`username`/`password`/`url`）、`ssh`（`host`/`username`/`public_key`/`private_key`/`passphrase`）；
  - `POST /v1/console/credentials/:id/reveal`（`Cache-Control: no-store`）支持分层受控返回：`scope: 'plain'` 仅返回 `secret: false` 字段供阅读态直出、绝不向浏览器下发机密值；传 `field` 仅返回单字段供盲拷或单行显露；默认 `scope: 'all'` 兼容旧调用；
  - 严格 `#field` 解析：显式请求不存在的 `#field` 直接 404 拒绝，严禁静默回退主值；`placeholderStatuses` 免解密核对 `field_meta`；新增 `GET /v1/console/credentials/:id/references` 反查活跃记忆引用；MCP `kioku_list_credentials` 仅透出字段名清单与类型元数据，绝不输出值。
- **P0 多入口凭据捕获与整理敏感提醒搭便车**：
  - 共享明文匹配升级为 `findSecretMatches`（覆盖现有高置信前缀、含密码连接串与 `Bearer <JWT>`，自动跳过明显占位示例降低误报），服务于**随手记**与**记忆创建/编辑**两处 P0 捕获入口；
  - 随手记反转安全默认：命中疑似明文时右下角唯一实色主按钮为「转存为凭据」，左下角低存在感「仍以明文发送」须经 `ConsequenceModal` 二次确认；记忆编辑器提供单行缺失凭据补建、选中文本转存与一键替换占位符；
  - LLM 整理（`standard` / `tidy`）在现有调用中零额外开销附带非回显 `secret_warnings`（严禁输出完整明文，解析器清洗截断），透传至整理页供人工核查。
- **凭据页与设置页体验收口**：
  - 凭据页升级为 `216px | 336px | 1fr` 纸墨三栏工作台：阅读态与编辑态彻底分离（明文直出、机密行内显示/盲拷/引用、访问范围折叠为 1 行摘要使引用记忆首屏可见），新建页改单层 10 秒复合录入流；
  - 设置页左轨收口为 6 项 + 极简版本尾标，全部子页共享居中同宽容器（`max-width: 820px / 780px`）；`终端与密钥` 单页收口（顶部接入条 + 浏览器授权弹窗 + 密钥清单 + 460px 右滑编辑抽屉）；`模型`（嵌入与索引、对话与整理、定时计划）补齐清除密钥、中文化思考等级与人性化周期；`账号与登录设备` 与 `备份与迁移` 补全静态用户名、浅灰禁用态、下线其他设备与单页自然流迁移。
