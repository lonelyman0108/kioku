## 决策摘要

1. **业务边界**：凭据识别大幅增强（厂商 Token、URL 密码、HTTP Header、钱包私钥/助记词）+ 核心 PII 默认开启（手机号、中国身份证、银行卡、邮箱）+ 低频/易误报 PII 默认关闭按空间开启（公网 IP、MAC、SSN、IBAN、护照）+ 抽取链路送审前不可逆脱敏（`[REDACTED:<KIND>]`）。
2. **落库与查询架构**：放弃实时 SQL `~*` 跑大正则；写入/修改时由完整 JS 引擎计算敏感命中并把结果（`sensitive_credential`、`sensitive_pii`、`sensitive_findings`、`sensitive_revision`）落库，列表筛选与待处理统计直接查库；规则或空间隐私配置变更时通过 pg-boss 后台任务分批异步回扫。
3. **处置策略**：
   - 新增明文凭据仍按原有门禁拦截（400 `MemoryWriteError`，支持显式放行进待处理、转存为 `{{cred:...}}` 或忽略）。
   - 仅检出 PII 时不强制阻断、不强制存密码库，写入后自动进待处理提醒，支持一键打码（`***` 或 `[REDACTED:<KIND>]`）或确认忽略当前版本。
   - 抽取链路：送外部抽取模型前对对话文本做不可逆占位打码，模型输出再做二次敏感扫描；候选事实需附带用户原话 `quote` 并由服务端规范化校验防幻觉。
4. **自定义与模型扩展**：支持空间级自定义规则（前缀/正则）与全局忽略词白名单；实例设置支持配置外部/本地隐私检测模型（HTTP NER 端点或 OpenAI 兼容小模型），空间按需开启。
5. **整理（Dream）高频晋升**：将 `memory_recall_stats` 传给整理模型，提示其优先把高频联系人事实提炼进 `user://` 记忆，并为高频策展记忆新增 `promote` 建议类型（建议设为重要或加入启动加载）。
