## 分阶段任务

### 1 · 服务端

- [x] 未知的 `/v1` 路径返回 `{ error }` 的 JSON 与 404，不再是纯文本的「404 Not Found」（管理界面的页面路由照旧）
- [x] `crypto/rotation.ts` 只改非键列的地方用 `FOR NO KEY UPDATE SKIP LOCKED`，外键插入的锁不再让它跳过
- [x] 实例的向量覆盖率不再逐个空间串行查询（每个空间仍在自己的事务里，几个空间同时数，整个进程合起来最多同时 4 个，主密钥卡片的计数也这样数；有一个出错就不再开始别的，等已开始的结束再报错）
- [x] editor 打开概览时应用表只查一次（对象页拒绝绑定只确认是成员、不再建记忆服务；凭据的成员检查也用同一个函数）
- [x] Key 的转换检查（改层与移动各写了一份）收成一个函数

### 2 · 管理界面的列表

- [ ] 凭据页的已删除列表、「已过期」里标「已让出」的记录显示大约几天后永久清除，规则与记忆的已删除列表一致（暂停结束的时间只给实例管理员）
- [ ] 已删除列表里，URI 已被别的记忆占用、撤销删除必然 409 的条目先标出来
- [ ] 活动流每一行对快照的可见性判断只算一次（事件多、看得到的少时不慢）
