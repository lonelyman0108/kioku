# 纸墨界面与底层架构概念对齐计划

保留原有「纸墨线框（Paper & Ink）+ 零圆角 + 1px 墨线 + 4 档敏感度 SVG 纹理 + 顶部导航」视觉底子，修正 `9274570` 中与 `v0.5.0` 后新架构错位的展现、补齐遗漏的前端配置入口，并统一收口面向用户的平实中文术语。

## 1. 核心设计决定

- **地层编码拆分为双视角**：
  - **单圈静态库存视角**（概览页 `StrataColumn`、记忆页左侧窄柱 `StrataRibbon`）：仅渲染当前记忆圈真实存在的 **3 类记忆形态**（虚线框：`会话摘要`、`联系人事实`；实线框：`正式记忆`，个人圈取 `--layer-personal` 暖金，独立圈取 `--layer-primary` 湖青）× **4 档敏感度纹理**，消除永远为 0 的主客场死带与无敏感度的独立人格假行；
  - **跨圈与客户端动态视野**（访问密钥岩芯 `StrataCore`、访问范围表 `AccessMatrix`、启动加载条 `AppSimulator`、召回试算 `RecallDebugPanel`、跨圈双链 `EntryLinksPanel`）：保留完整 6 色（`主圈记忆`、`独立人格`、`关联圈记忆`、`个人圈记忆`、`联系人事实`、`会话摘要`）区分真实跨圈来源；
  - 同圈内记忆标签统一显示真实形态名（`正式记忆` / `联系人事实` / `会话摘要`），不再在单圈视图称「主场 / 客场」。
- **顶部单栏导航精简为 9 项**：
  - 左端：`記憶` 字标 + 记忆圈切换器（置顶唯一不可删的 `个人圈`、下方列 `独立圈`，仅成员 > 1 时显示协作人数；底部提供 `新建独立圈`、`导入记忆圈`）；
  - 核心组（6 项）：`概览` · `记忆` · `对话` · `人格`（独立顶层页） · `凭据` · `待处理（角标）`；
  - 接入与治理组（3 项）：`客户端`（含 `客户端与密钥` · `召回与试算` · `测试台` 二级页签） · `变更记录` · `设置`（记忆圈设置新增 `语境词典` 小节）；
  - 右端：`⌘K` 跨圈搜索、主题切换、账号菜单。
- **补齐底层架构前端闭环**：
  - 记忆圈概况与新建独立圈支持配置 `defaultFacets`（默认适用条件），记忆新建与详情展示本圈默认条件沿用说明；
  - 记忆详情与编辑器严格对齐 `entry / fact / episode` 三种形态的物理约束（仅 `entry` 开放跨圈迁移且拦截含个人凭据引用的迁出；`episode` 隐藏多变体、适用条件、机密与 P0；单无条件变体默认折叠条件选择器实现轻编辑；机密多变体锁定同场域）；
  - 移除单圈记忆目录中无意义的「按记忆圈分组」；
  - 跨圈 `[[m-xxxxxx]]` 双链点击先打开右侧纸墨风只读预览抽屉，确认后再切圈；
  - 客户端与密钥配置分清「默认语境（动态焦点）」与「访问范围与硬边界（静态上限）」；群聊会话详情内联展示并支持切换当前人格与单群隔离锁；凭据页明确区分个人圈与独立圈语义。
- **统一界面用语**：采用 `个人圈 / 独立圈`、`记忆（正式记忆 / 联系人事实 / 会话摘要） / 变体`、`适用条件 / 语境词典 / 自动关联 / 唤醒别名 / 单选互斥 / 多选叠加`、`召回说明`、`客户端`、`访问范围 / 主圈 / 关联圈`、`跨群认人 / 按群隔离 / 单群隔离锁 / 本人私聊开放内部记忆`。
