# 记忆列表改版与随手记自动归并计划

聚焦解决 Kioku v0.6.0 管理界面「记忆」页的两个核心痛点：

1. **列表标题可读性（方案 A + 统一线轨图例）**：放弃默认 360px 窄栏 + 75% 空白右栏，改为「默认全宽清单 + 右侧按需抽屉（Side Peek）+ 一键全屏展开」；将 13 个项目与 99% 覆盖率的 `topics`、环境、场域及「无项目归属」收纳至顶栏单行下拉筛选；以「3px 左缘实线（常驻）/ 湖色虚线（摘要）+ 纯标题 100% 左缘对齐 + 副行状态文字 + 顶栏分段图例」彻底解决样式参差问题。
2. **随手记自动归并（方案 3 + 方案 1 降级）**：在记忆页顶栏（及 `⌘J` / `⌘K`）提供单框「随手记」入口，经「混合召回 Top-5 + 通用常驻核心块 → 单次 LLM 局部补丁（不重写全文）→ 原地行级 Diff 一键确认」归并入既有大块记忆；支持候选目标切换、「改为文末追加」「存为新记忆」逃生舱、双链与凭据占位符完整性校验、乐观锁更新与通知条一键回滚；未配置对话模型或模型不可用时无感降级为「检索选目标 + 小节确定性追加」。

不新增数据库表与迁移，不新增顶级导航（保持 3+1），不引入闪念/每日笔记新数据物种。
